# mizprism.github.io

MIZPRISM の公式サイト https://mizprism.github.io/ の中身です。MIZPRISM は、VRChat のワールドやアバターを作る人のための Unity の道具を作っています。

## 置いているファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | トップのページ。MizFR World と MizEye の紹介と、問い合わせ先を載せています |
| `manual.html` | MizFR World の説明書の全文です。購入した zip に入っている説明書と同じ原稿から作っています |
| `site.css`、`glass.js`、`page.js`、`toc.js` | ページの見た目と動き |
| `assets/` | 背景の写真、ロゴ、共有用の画像、アイコン |
| `fonts/` | ページで使うフォント (IBM Plex Sans JP、IBM Plex Sans、Lexend Zetta) |

ページは、このリポジトリの外からは何も読み込みません。

`https://mizprism.github.io/mizfr/` と `https://mizprism.github.io/mizeye/` は、それぞれ [mizfr](https://github.com/mizprism/mizfr) と [mizeye](https://github.com/mizprism/mizeye) のリポジトリから配信しています (VCC のパッケージの一覧など)。このリポジトリには、`mizfr` と `mizeye` という名前のフォルダーを置きません。置くと、その 2 つの配信と同じ住所になるためです。

## フォントと画像

フォントはどれも SIL Open Font License 1.1 で、各フォルダーに `LICENSE` と、入手元を書いた `SOURCE.txt` を置いています。背景の写真は ChatGPT で生成した画像で、MIZPRISM のロゴはいまは仮の文字です。
